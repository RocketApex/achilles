# Achilles 1.1.4

Achilles now looks up each component ID directly when registering it. Duplicate
IDs still prevent registration. Text-only DOM changes no longer trigger a
component scan. On Turbo Frame replacement, Achilles finds the outgoing
components inside the frame and tears down children before their parents.

## Upgrading

Update to `1.1.4` using the existing component markup and registration code.
Verify Turbo Frame replacement, browser history restoration, and dynamic
component insertion in your application. If you are upgrading from a version
earlier than `1.1.0`, start with the [1.1.0 upgrade guide](../upgrading-to-1.1.0.md).
