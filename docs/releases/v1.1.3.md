# Achilles 1.1.3

Achilles now looks up component class names and IDs only among registered
entries. This fixes lookups when a class name or ID matches a built-in
JavaScript object property.

## Upgrading

Update the Achilles gem to `1.1.3` and keep your existing component markup and
registration code. If you are upgrading from a version earlier than `1.1.0`,
start with the [1.1.0 upgrade guide](../upgrading-to-1.1.0.md).
